# Plugin Plan

**Phase:** 07 — Plugin Architecture (see `CLAUDE.md` §11)
**Status:** Not started

Select only the plugins necessary for the approved requirements. Prefer official, maintained, lightweight
plugins and avoid duplicate functionality. Never install a plugin merely because it is commonly used or
because it appears in the matrix below — the matrix records the decision, it doesn't make it.
