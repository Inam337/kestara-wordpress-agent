# Asset Inventory

**Phase:** 04 — Design Handoff (see `CLAUDE.md` §8, §29 Asset Architecture)
**Status:** Not started

Recommended asset structure:

```text
assets/
├── images/
│   ├── content/
│   ├── backgrounds/
│   ├── banners/
│   └── thumbnails/
├── logos/
├── icons/
└── fonts/
```

Rules: descriptive filenames, no unnecessary duplicates, optimize dimensions/formats, lazy-load
below-the-fold images, don't unnecessarily preload normal page images, remove unused assets, avoid loading
page-specific assets globally.
